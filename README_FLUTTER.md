# FlareMusic — Flutter rewrite

This branch contains the separate Flutter/Dart rewrite in progress. The existing Kotlin app on `main` is unchanged.

## Run
Install Flutter, then run:

```sh
flutter pub get
flutter run
```

## Status
- Initial Flutter project scaffold and Material 3 home-screen prototype.
- Playback, account, YouTube Music, playlist synchronization, and persistence are not yet migrated.
